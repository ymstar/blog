一、安装JDK1.8

首先检查Linux系统上是否有JDK，一般Linux系统会有默认的openJDK，将其卸载掉。

三、安装Redis5.0.4

安装依赖：

yum install gcc-c++

到官网下载压缩包，上传到Linux系统，并解压。

tar -zxvf redis-5.0.4.tar.gz // 直接解压到当前目录即可

进入刚刚解压的redis-5.0.4目录，在该目录下执行 make 命令，进行编译。
